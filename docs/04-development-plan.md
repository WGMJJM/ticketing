# 分阶段开发计划

当前已完成工程基线、活动场次、票档库存、用户认证、订单、模拟支付、超时关单、候补调度、电子票与核销，以及第八阶段性能评估和有证据支持的Outbox发布调整。保留原库存、身份和签名协议，未修改连接池默认或新增业务索引。第八阶段验收后停止，不自动进入整体重构、真实支付或退款。

| 顺序 | 开发范围 | 阶段验收重点 |
| --- | --- | --- |
| 1 已完成 | 活动与场次管理、发布及公开查询 | 已验证公开可见性、状态流转、时间语义、管理权限 |
| 2 已完成 | 票档管理、总库存调整与开售状态查询 | 整数分、库存不变量、父子窗口、权限及并发编辑冲突 |
| 3 已完成 | 用户注册登录、退出、个人中心与管理员权限 | BCrypt、真实Session与Cookie、CSRF、刷新恢复、会话固定攻击防护、越权测试 |
| 4 已完成 | 下单与库存预占、订单查询与主动取消 | 同事务条件库存更新、用户行锁保护跨票档限购、幂等同参/异参、真实HTTP并发、失败回滚与浏览器库存恢复 |
| 5 已完成 | 模拟支付与MySQL超时扫描 | 支付/取消/过期同锁序、数据库截止条件、库存只变一次、唯一真实流水、禁用账号清理、失败隔离与重启补偿 |
| 6 已完成 | 同票档 FIFO 候补与自动调度 | SKU锁内入队、队首阻塞、WAITLIST_CONFIRM、订单终态联动、Outbox确认/租约/重试、真实RabbitMQ死信及数据库补偿 |
| 7 已完成 | 电子票与核销 | 同事务按量出票、受控补票、HMAC轮换/摘要、本人二维码、真实ADMIN扫码及最多一次核销 |
| 8 已完成 | 并发测试与性能评估 | 独立环境52组实测、库存与交易审计、10类故障恢复、发布批量控制实验、完整153项后端回归和Vue真实闭环 |

每阶段补充迁移、真实 API、页面及有意义的测试；不提前生成空层次。真实支付、座位图、实名核验、退款对账和多租户均不在当前计划。性能结论必须来自可复现的压测与一致性核对，不以字段设计、消息发送或静态 CHECK 测试代替。
