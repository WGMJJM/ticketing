# 前端配色与界面优化验收

本次接续第十三阶段已完成的实现，仅调整前端视觉和服务状态文案。后端源码、数据库迁移、接口调用、Store、路由及业务状态判断均未修改。

## 视觉调整

- 使用雾白背景、白色内容面板和深青绿主色，分类卡片以淡紫、浅绿、桃色和浅蓝区分。
- 统一导航选中态、按钮、输入框、焦点轮廓、卡片圆角、边框和阴影，覆盖首页、活动详情、登录注册、个人中心、订单、电子票、管理表格及核销页面。
- 保留原有 SVG 插画，调整配色、位置和底部遮罩，改善文字与插画重叠处的可读性。
- 加深次要文字颜色，修复 320px 视口下受滚动条影响的横向溢出；窄屏表格在容器内滚动，弹窗操作按钮保持可达。
