# 第二阶段票档与库存管理验收

验收日期：2026-10-17。本轮在现有 main 工程中完成票档与库存管理，保持 Java 21、Spring Boot 3、MyBatis-Plus、MySQL 及 Vue 3、TypeScript、Element Plus；没有新增 Maven 模块或基础设施。

## 已交付行为

- 管理员创建草稿、查询、编辑、启用销售与下架；同场次票档名唯一，使用 version 条件更新防止覆盖。
- 总库存可调整，锁定与已售库存不可通过管理请求写入；可售量始终计算为总量减锁定减已售，不新增存储字段。
- ON_SALE 只能调整总库存；名称、价格、窗口及限购需先下架后修改。
- 场次开售是所有票档的最早开售边界，满足 `场次开售 <= 票档开售 < 票档停售 <= 场次开始`；修改场次与票档共享场次行锁。旧数据窗口矛盾时返回暂不可售。
- 后端统一计算暂未开售、正在售票、已售罄、已停售、暂不可售；公开查询隐藏草稿和下架票档，校验活动发布与场次归属。
- 用户端选择场次自动查询票档；管理端沿用活动与场次页面入口、开发管理员和 CSRF。界面显示北京时间、人民币和中文状态，没有模拟购票成功。

## 浏览器与真实接口联调

本机通过 Vite 代理连接启动的 Spring Boot 与 MySQL，未使用模拟 API。

1. 手动导入显式标记为演示的 `scripts/demo-tickets.sql`。活动详情选择“票档状态体验场（演示）”，真实展示停售票99元、零配额票199元、标准票299元、即将开售票399元，分别显示已停售、已售罄、正在售票、暂未开售，库存与服务端响应一致。
2. 使用本地被忽略的 `.env` 开发管理员凭据认证，在活动的“场次 → 票档管理”中创建“浏览器验收票（演示）”，票价123.45元、库存12，结果为草稿；重名创建显示“同一场次已存在同名票档”。
3. 确认启用销售后名称与价格输入禁用、库存输入可用，将总库存调到13，价格仍为123.45元、锁定与已售仍为0。确认下架后可编辑为128.56元，公开查询不再包含此下架票档。
4. 原演示展览的空场次显示“该场次暂无已公开票档”。实际暂停本地后端后刷新票档，出现中文连接错误与重试按钮；重启后端，点击重新加载恢复真实空状态。
