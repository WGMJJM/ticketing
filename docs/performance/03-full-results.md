# 同场景完整压测结果

以下48行来自已保存的k6与MySQL原始统计，由scripts/performance/report.py重新计算，按场景及10/25/50/100 VU排序。正式基线与最终代码各24组，单参数控制及补充监测4组另存原始目录，不混入本表。

每组预热10秒、稳定20秒。RPS及成功创建订单TPS只用完成时间落在稳定窗口的计数；关联支付成功数包含相应订单收尾，用于结果核对，不是支付TPS。P50/P95/P99来自该窗口请求样本。MySQL累计锁等待含预热及收尾，与稳定HTTP计数时间范围不同。同票核销的预期409是重复拒绝，候补的HTTP请求包含轮询。

相同模型下单轮吞吐会波动，最终表不能单独证明某项改动因果收益。发布批量的独立参数对照、部分SENT延迟的截尾限制及未采用的连接池调整见[分析报告](02-analysis.md)。机器与配置见[环境快照](results/hardware.json)，完整计数见[comparison.json](results/comparison.json)，各轮原始文件位于results/baseline及results/optimized。
